### 課題 2-2：クラスとオブジェクト

`Part.java` を作成し、以下を実装すること。

| フィールド | 型 | 説明 |
|---|---|---|
| `partCode` | `String` | 部品コード（例：`P001`） |
| `partName` | `String` | 部品名（例：`ボルト M6`） |
| `stock` | `int` | 在庫数 |
| `warehouseCode` | `String` | 倉庫コード（例：`WH01`） |

実装すること：
- すべてのフィールドを引数に持つコンストラクタ
- 各フィールドの getter / setter
- `toString()` メソッド（内容を読みやすい形式で返す）
- `isLowStock(int threshold)` メソッド（在庫数が閾値以下なら `true` を返す）

`PartTest.java` を作成し、以下を確認するコードを書くこと：
- `Part` インスタンスを 3 件作成してコンソールに表示する
- `isLowStock(10)` が正しく動くことを確認する

### 課題 2-3：継承とインターフェース

以下のクラス・インターフェースを作成すること。

```java
// インターフェース
public interface Printable {
    void printInfo();
}
```

- `Part` クラスに `Printable` を実装し、`printInfo()` で部品情報をコンソール出力する
- `Part` を継承した `ManagedPart` クラスを作成し、フィールドとして `String manager`（担当者名）を追加する
- `ManagedPart` の `printInfo()` をオーバーライドし、担当者名も出力する

`InheritanceSample.java` の `main` メソッドで `Printable` 型の変数に `Part` と `ManagedPart` それぞれを代入し、`printInfo()` を呼び出すこと（ポリモーフィズムの確認）。

### 課題 2-5：例外処理

`ExceptionSample.java` を作成し、以下を実装すること。

1. 独自例外クラス `StockException` を作成する（`RuntimeException` を継承）
2. `Part` クラスに `decreaseStock(int quantity)` メソッドを追加する
   - 在庫数を `quantity` 分減らす
   - 在庫数が 0 未満になる場合は `StockException` をスローする
   - メッセージ例：`「在庫不足：要求数=10, 現在庫=5」`
3. `main` メソッドで `decreaseStock` を呼び出し、正常系・異常系の両方を `try-catch` で処理する

---

### 課題 2-6：Stream API とラムダ式

`StreamSample.java` を作成し、以下を実装すること。

`List<Part>` に 5 件以上のデータを用意した上で：

1. 在庫数が 10 以下の部品のみ抽出してコンソールに出力する（`filter`）
2. 全部品の部品名の一覧を `List<String>` として取得して出力する（`map` + `collect`）
3. 全部品の在庫数の合計を計算して出力する（`mapToInt` + `sum`）
4. 在庫数が多い順に並べて出力する（`sorted`）

## 提出・確認方法

各課題を実装したら担当者に声をかけること。以下の形式で確認を行う。

1. コードを Eclipse で開いた状態で実行デモをする
2. 担当者からコードについて質問される（「このメソッドは何をしているか」「なぜこう書いたか」など）
3. 口頭で説明できること

> **注意：** ネットで調べたコードをそのままコピーするのではなく、理解した上で自分の言葉で説明できるようにしておくこと。
