## アプリの全体的な動き

アプリを起動するとメインメニューが表示される。番号を入力して各機能に進み、
操作が完了すると **自動的にメインメニューに戻る**。`0` を入力するまでこれを繰り返す。

```
起動
  └─→ メインメニュー表示
         └─→ 番号入力
               ├─→ 各機能の処理（入力待ち → 実行 → 結果表示 → 一覧表示）
               │        └─→ メインメニューに戻る  ← 繰り返し
               └─→ 0 入力 → 終了
```

> **ポイント：** 登録・更新・削除の処理が完了したら、その場で一覧を自動表示して
> 反映されていることをその場で確認できるようにすること。

## 作成するクラス

### Part クラス（`model/Part.java`）

部品 1 件のデータを表すクラス。

| フィールド | 型 | 説明 | 例 |
|---|---|---|---|
| `partCode` | `String` | 部品コード（ユニーク） | `P001` |
| `partName` | `String` | 部品名 | `ボルト M6` |
| `stock` | `int` | 在庫数（0 以上） | `100` |
| `warehouseCode` | `String` | 倉庫コード | `WH01` |

実装すること：
- 全フィールドを引数に持つコンストラクタ
- 各フィールドの getter / setter
- `toString()` メソッド

---

### InventoryService クラス（`service/InventoryService.java`）

内部で `List<Part>` を保持し、部品データの操作をすべて担当するクラス。
**Main クラスからは必ずこのクラスを経由してデータを操作すること。**

| メソッド | 説明 |
|---|---|
| `List<Part> findAll()` | 全部品を返す |
| `Part findByCode(String partCode)` | 部品コードで検索して返す（なければ `null`） |
| `void add(Part part)` | 部品を追加する。同じ部品コードが存在する場合は例外をスロー |
| `void updateStock(String partCode, int newStock)` | 在庫数を更新する。新在庫数が 0 未満の場合は例外をスロー |
| `boolean delete(String partCode)` | 部品コードで削除する。削除できた場合は `true`、見つからない場合は `false` を返す |

---

### Main クラス（`app/Main.java`）

ユーザーの入力を受け付けて `InventoryService` を呼び出し、結果をコンソールに表示するクラス。
`Scanner` を使って標準入力から値を受け取る。

## 各機能の詳細仕様

### メインメニュー

アプリ起動時・各操作完了後に表示される。
番号を入力して Enter を押すと対応する機能に進む。

```
===== 部品在庫管理システム =====
1. 部品一覧表示
2. 部品登録
3. 在庫数更新
4. 部品削除
5. 部品検索
0. 終了
> ここに番号を入力して Enter
```

---

### 機能 1：部品一覧表示

**何をする画面か：**
現在メモリ上に登録されている全部品を一覧形式で表示する。データの確認専用で、入力は不要。

**操作の流れ：**
1. メニューで `1` を入力
2. 全部品が一覧で表示される（入力不要）
3. 自動的にメインメニューに戻る

**表示例：**
```
===== 部品一覧 =====
部品コード  部品名            在庫数   倉庫
----------------------------------------------
P001       ボルト M6          100     WH01
P002       ナット M6           50     WH01
P003       ワッシャー M6       200     WH02
----------------------------------------------
3 件表示

> メインメニューに戻ります...
```

**データが 0 件の場合：**
```
===== 部品一覧 =====
登録されている部品はありません。

> メインメニューに戻ります...
```

---

### 機能 2：部品登録

**何をする画面か：**
新しい部品を 1 件登録する。部品コード・部品名・在庫数・倉庫コードを順番に入力する。
登録後は一覧を自動表示して、追加されたことをその場で確認できる。

**操作の流れ：**
1. メニューで `2` を入力
2. 部品コード・部品名・在庫数・倉庫コードを 1 項目ずつ入力（Enter で次へ進む）
3. `InventoryService.add()` で登録
4. 「登録しました」と表示
5. **一覧を自動表示**（反映確認）
6. メインメニューに戻る

**操作例（正常）：**
```
--- 部品登録 ---
部品コード（例：P004）: P004
部品名: スプリング
在庫数（0以上の整数）: 30
倉庫コード（例：WH01）: WH02

登録しました。

===== 部品一覧（更新後）=====
部品コード  部品名            在庫数   倉庫
----------------------------------------------
P001       ボルト M6          100     WH01
P002       ナット M6           50     WH01
P003       ワッシャー M6       200     WH02
P004       スプリング           30     WH02  ← 追加された
----------------------------------------------
4 件表示

> メインメニューに戻ります...
```

**操作例（エラー：同一部品コードが存在する場合）：**
```
--- 部品登録 ---
部品コード（例：P004）: P001
部品名: テスト

エラー：部品コード P001 はすでに登録されています。
もう一度登録する場合はメインメニューから選択してください。

> メインメニューに戻ります...
```

---

### 機能 3：在庫数更新

**何をする画面か：**
既存の部品の在庫数を変更する。部品コードを入力して対象を指定し、新しい在庫数を入力する。
更新後は一覧を自動表示して変更が反映されたことを確認できる。

**操作の流れ：**
1. メニューで `3` を入力
2. 更新したい部品コードを入力
3. 現在の在庫数が表示される（確認用）
4. 新しい在庫数を入力
5. `InventoryService.updateStock()` で更新
6. 「更新しました」と表示
7. **一覧を自動表示**（反映確認）
8. メインメニューに戻る

**操作例（正常）：**
```
--- 在庫数更新 ---
更新する部品コード: P001

現在の情報：P001 / ボルト M6 / 在庫数：100 / WH01

新しい在庫数: 150
更新しました。（P001：100 → 150）

===== 部品一覧（更新後）=====
部品コード  部品名            在庫数   倉庫
----------------------------------------------
P001       ボルト M6          150     WH01  ← 更新された
P002       ナット M6           50     WH01
P003       ワッシャー M6       200     WH02
----------------------------------------------
3 件表示

> メインメニューに戻ります...
```

**操作例（エラー：在庫数がマイナスの場合）：**
```
新しい在庫数: -10
エラー：在庫数は 0 以上で入力してください。

> メインメニューに戻ります...
```

**操作例（エラー：部品コードが存在しない場合）：**
```
更新する部品コード: P999
エラー：部品コード P999 は見つかりませんでした。

> メインメニューに戻ります...
```

### 機能 4：部品削除

**何をする画面か：**
既存の部品を 1 件削除する。誤削除防止のため、削除前に確認を求める。
削除後は一覧を自動表示して、消えたことを確認できる。

**操作の流れ：**
1. メニューで `4` を入力
2. 削除したい部品コードを入力
3. 対象部品の情報が表示され「削除しますか？(y/n)」と確認を求められる
4. `y` を入力すると削除実行、`n` を入力するとキャンセル
5. 削除後は**一覧を自動表示**（反映確認）
6. メインメニューに戻る

**操作例（正常）：**
```
--- 部品削除 ---
削除する部品コード: P004

削除対象：P004 / スプリング / 在庫数：30 / WH02
本当に削除しますか？(y/n): y

削除しました。

===== 部品一覧（更新後）=====
部品コード  部品名            在庫数   倉庫
----------------------------------------------
P001       ボルト M6          150     WH01
P002       ナット M6           50     WH01
P003       ワッシャー M6       200     WH02
----------------------------------------------
3 件表示

> メインメニューに戻ります...
```

**操作例（キャンセル）：**
```
本当に削除しますか？(y/n): n
削除をキャンセルしました。

> メインメニューに戻ります...
```

**操作例（エラー：部品コードが存在しない場合）：**
```
削除する部品コード: P999
エラー：部品コード P999 は見つかりませんでした。

> メインメニューに戻ります...
```

### 機能 5：部品検索

**何をする画面か：**
部品コードを入力して、1 件の部品情報を検索・表示する。
一覧では見づらい場合に特定の部品だけを確認したいときに使う。入力と結果表示のみで、データは変更しない。

**操作の流れ：**
1. メニューで `5` を入力
2. 検索したい部品コードを入力
3. 見つかれば 1 件分の詳細情報を表示、見つからなければエラーを表示
4. メインメニューに戻る

**操作例（正常）：**
```
--- 部品検索 ---
検索する部品コード: P001

===== 検索結果 =====
部品コード  : P001
部品名      : ボルト M6
在庫数      : 150
倉庫コード  : WH01

> メインメニューに戻ります...
```

**操作例（見つからない場合）：**
```
--- 部品検索 ---
検索する部品コード: P999

エラー：部品コード P999 は見つかりませんでした。

> メインメニューに戻ります...
```

## 業務ルール

| ルール | 内容 |
|---|---|
| 部品コードの重複禁止 | 同じ部品コードは登録できない |
| 在庫数は 0 以上 | 登録・更新ともに 0 未満は不可 |
| 存在チェック | 更新・削除は存在しない部品コードを指定するとエラー |
| 削除前確認 | 削除は `y/n` の確認入力を必須とする |
| 操作後の一覧表示 | 登録・更新・削除が成功した場合は必ず一覧を自動表示する |

## 実装のヒント

### Scanner での入力受付

```java
Scanner scanner = new Scanner(System.in);

System.out.print("部品コード: ");
String partCode = scanner.nextLine();  // 文字列は nextLine()

System.out.print("在庫数: ");
int stock = Integer.parseInt(scanner.nextLine());  // 数値は nextLine() で受けて parseInt()
```

> `nextInt()` を使うと改行が残り次の入力がずれることがあるため、
> **数値も `nextLine()` で受けてから `parseInt()` で変換する**こと。

### メニューループの基本構造

```java
while (true) {
    printMenu();               // メニュー表示
    String input = scanner.nextLine();

    switch (input) {
        case "1" -> showList();
        case "2" -> addPart();
        // ...
        case "0" -> {
            System.out.println("アプリを終了します。");
            return;
        }
        default -> System.out.println("無効な入力です。0〜5 の番号を入力してください。");
    }
}
```
