**フェーズ：** Phase 2-B　**期間目安：** 4〜5 日　**担当：** 新人

## 目的

コンソールアプリで作った「部品在庫管理」に Web 画面を追加する。
Jakarta EE の Servlet と JSP を使って、ブラウザから操作できるようにする。

---

## 背景

現在のアプリはコンソール（文字画面）でしか操作できません。
実際の業務システムは Web ブラウザから使うものがほとんどです。

まず Jakarta EE（Servlet + JSP）で実装する理由：
- レガシーシステムには Servlet/JSP ベースのものが多い
- 「Spring Boot が何を楽にしてくれているか」を後で比較するため

## 実装する画面・機能

### 画面一覧

| 画面 | URL | 説明 |
|---|---|---|
| 部品一覧 | `/parts` | DB から部品一覧を取得して表示 |
| 部品登録フォーム | `/parts/add` (GET) | 登録フォームを表示 |
| 部品登録処理 | `/parts/add` (POST) | フォームの値を受け取って DB に INSERT |
| 在庫更新処理 | `/parts/stock` (POST) | 在庫数を更新する |
| エラー画面 | `/error` | エラーが発生した場合に表示 |

---

### ① 部品一覧画面（`PartListServlet.java` + `part_list.jsp`）

**Servlet の処理：**
1. `InventoryService.findAll()` で部品一覧を取得する
2. `request.setAttribute("parts", parts)` でリクエストスコープに渡す
3. `part_list.jsp` にフォワードする

**JSP の表示：**
```
===== 部品一覧 =====

[部品登録]ボタン

部品コード | 部品名       | 在庫数 | 倉庫コード | 操作
P001      | ボルト M6    | 100   | WH01      | [在庫更新]
P002      | ナット M6    |  50   | WH01      | [在庫更新]
P003      | ワッシャー M6| 200   | WH02      | [在庫更新]
```

- EL 式（`${part.partCode}` など）と JSTL（`<c:forEach>`）を使うこと
- 在庫数が 10 以下の行は背景色を変えるなど、視覚的に区別すること（CSS で可）

---

### ② 部品登録（`PartAddServlet.java` + `part_add.jsp`）

**GET（フォーム表示）：**
- 入力フォームを表示する（部品コード・部品名・在庫数・倉庫コード）

**POST（登録処理）：**
1. フォームの値を `request.getParameter()` で受け取る
2. バリデーションを行う（後述）
3. `InventoryService.add(part)` で登録する
4. 成功したら部品一覧画面にリダイレクトする（PRG パターン）
5. 失敗したら登録フォームに戻りエラーメッセージを表示する

**バリデーション：**

| 項目 | チェック内容 |
|---|---|
| 部品コード | 必須・英数字のみ・10 文字以内 |
| 部品名 | 必須・100 文字以内 |
| 在庫数 | 必須・整数・0 以上 |
| 倉庫コード | 必須・英数字のみ・10 文字以内 |

---

### ③ 在庫更新（`StockUpdateServlet.java` + `part_stock_update.jsp`）

**何をする画面か：**
一覧画面の「在庫更新」ボタンを押すと更新フォームが開く。
現在の在庫数を確認しながら新しい在庫数を入力して更新する。
更新後は一覧にリダイレクトし、フラッシュメッセージで完了を知らせる。

**画面遷移：**
```
部品一覧画面
  └─[在庫更新]ボタン押下（部品コードを URL パラメータで渡す）
        └─→ 在庫更新フォーム（GET）
              └─→ 新在庫数を入力して送信（POST）
                    ├─→ 成功：部品一覧にリダイレクト（「更新しました」メッセージ）
                    └─→ 失敗：フォームに戻りエラーメッセージを表示
```

**GET（フォーム表示）：**
1. URL パラメータから部品コードを受け取る（例：`/parts/stock?partCode=P001`）
2. `InventoryService.findByCode()` で現在の部品情報を取得する
3. 現在の在庫数を表示しながら新しい在庫数を入力できるフォームを表示する

**フォーム表示例：**
```
--- 在庫数更新 ---
部品コード : P001
部品名     : ボルト M6
現在の在庫 : 100

新しい在庫数: [____]

[更新する] [キャンセル]
```

**POST（更新処理）：**
1. 部品コードと新在庫数を受け取る
2. バリデーション：在庫数は 0 以上の整数
3. `InventoryService.updateStock()` で更新する
4. 成功したら部品一覧画面にリダイレクトする（PRG パターン）
5. 失敗したらフォームに戻りエラーメッセージを表示する

**バリデーション：**

| 項目 | チェック内容 |
|---|---|
| 在庫数 | 必須・整数・0 以上 |

---

### ④ エラー画面（`error.jsp`）

例外が発生した場合に表示するエラー画面。

- エラーメッセージを表示する
- 「一覧に戻る」リンクを表示する
- `web.xml` でエラーページを設定すること

```xml
<!-- web.xml の例 -->
<error-page>
    <error-code>404</error-code>
    <location>/jsp/error.jsp</location>
</error-page>
<error-page>
    <error-code>500</error-code>
    <location>/jsp/error.jsp</location>
</error-page>
```

## 実装上の注意

| 項目 | 注意内容 |
|---|---|
| PRG パターン | POST 後は必ず `sendRedirect` でリダイレクトすること（ブラウザの再送信問題を防ぐ） |
| XSS 対策 | JSP で値を出力する際は `<c:out value="${...}"/>` を使うこと（`${...}` の直接出力は NG） |
| JSTL | `pom.xml`（または `lib`）に JSTL の依存を追加すること |
| セッション | 今回はセッションを使わなくて良い |
