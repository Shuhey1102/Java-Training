# Java トレーニング

## 背景・目的

業務システム開発の現場に入る方を対象に、Java の基礎から実践的な Web アプリ・バッチ処理までを
一通り学べる教材として作成しました。
実務でつまずきやすいポイントを踏まえ、なるべく実践に近い形で組んでいます。

同じように Java を学び始める方の参考になれば、自由に使ってください。

---

## 対象者

- 新卒・第二新卒、または他言語から Java に入る中途メンバー
- Java の文法を多少触ったことがある〜ほぼ未経験の方

## 前提知識

- 基本的な PC 操作ができること
- プログラミングの基礎的な考え方（変数・条件分岐・繰り返し）があると望ましい（必須ではない）

---

## 教材のテーマ

**部品在庫管理システム** をお題に、設計・実装・テストを一通り体験してもらう構成です。
実際の製造業の業務（在庫・入出庫まわり）をイメージしやすいテーマを選んでいます。

コンソールアプリ → Web アプリ → バッチ処理と段階的にステップアップする構成になっています。

## 学習の進め方（新人向け）

- 各フォルダの仕様書（`spec_xx_xxx.md`）を順番に読んで進めてください
- わからない点はメモを残しつつ、都度質問してもらって構いません
- 演習課題は写経ではなく、**まず自分で考えてから**取り組んでください
- 30 分調べても解決しない場合は担当者に相談してください（「〇〇を調べたが△△がわからない」という形で）
- 各課題の最後に提出・確認があります。担当者にデモと口頭説明ができる状態にしてから声をかけてください

---

## 担当者向けメモ

| 観点 | 内容 |
|---|---|
| レベル確認 | 課題② で自走できるかを見極め、遅ければ課題③ の開始を 1 週ずらす |
| 定期確認 | 週次で「詰まっていること」を聞く 15 分の確認を設けると失踪リスクが下がる |
| 初 PR レビュー | 課題⑥ のタイミングで実施。コメントの書き方・受け取り方も教える |
| テーマの一貫性 | 全課題を通じて「部品在庫管理」で統一。題材が変わると学習効率が落ちる |
