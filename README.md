# Javaトレーニング
 
## 背景・目的
 
新しいメンバーが配属されることになったのをきっかけに、Java(および業務システム開発の基礎)を一通り学べる教材として作成しました。
自分自身が過去に学んだ内容や、実務でつまずいたポイントを踏まえて、なるべく実践に近い形で組んでいます。
 
社内向けに作ったものですが、同じようにJavaを学び始める方の参考になれば嬉しいので、よかったら自由に使ってください。
 
## 対象者
 
- 新卒・第二新卒、または他言語からJavaに入る中途メンバー
- Javaの文法は多少触ったことがある〜未経験の方
## 前提知識
 
- 基本的なPCの操作
- プログラミングの基礎的な考え方(変数、条件分岐、繰り返し 程度)があると望ましい(必須ではない)
## 教材のテーマ
 
**部品在庫管理システム**をお題に、要件定義〜実装〜簡単なテストまでを一通り体験してもらう構成です。
実際の業務(在庫・受発注まわり)をイメージしやすいテーマを選んでいます。
 
## 使用環境
 
- Eclipse
- SQL Server LocalDB
- Java(バージョンは各自の開発環境に合わせて記載予定)
## 進め方の目安
 
全体でおよそ1〜3ヶ月を想定しています。
 
1. 環境構築
2. Java基礎文法
3. オブジェクト指向の基礎
4. DB接続・CRUD処理
5. 部品在庫管理システムの実装(要件〜設計〜実装)
6. 簡単なテスト・振り返り
※進捗やレベル感に応じて期間は調整してください。
